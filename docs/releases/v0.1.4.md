# Rocky v0.1.4

## Highlights

- Rocky desktop updates use the public Rocky Release repository.
- Windows installer delivery is verified with a SHA-256 checksum manifest.

## Windows Install

Run `Rocky-Setup-v0.1.4.exe` on Windows. The installer updates the Rocky app
payload while preserving user state and local runtime settings.

## Validation

The release workflow runs typecheck, the full Node test suite, Windows
installer packaging, and source-free payload validation before publication.

## Checksums

Download `SHA256SUMS.txt` with the installer and verify the installer's SHA-256
digest before running it.

## Known Limitations

This is an unsigned Windows preview. Windows SmartScreen may display a warning
before installation.
