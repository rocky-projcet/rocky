# Rocky v0.1.4

## Highlights

- Rocky desktop updates use the public Rocky Release repository.
- Windows and macOS installer delivery is verified with a SHA-256 checksum manifest.
- macOS releases include Apple Silicon and Intel artifacts.

## Windows Install

Run `Rocky-Setup-v0.1.4.exe` on Windows. The installer updates the Rocky app
payload while preserving user state and local runtime settings.

## macOS Install

Use the matching architecture-specific installer:

- Apple Silicon: `rocky-v0.1.4-macos-arm64.pkg`, `.dmg`, or `.app.zip`
- Intel: `rocky-v0.1.4-macos-x64.pkg`, `.dmg`, or `.app.zip`

The PKG installs Rocky at `/Applications/Rocky.app` while preserving per-user
state and local runtime settings.

## Validation

The release workflow runs typecheck, the full Node test suite, macOS bundle and
PKG contract checks, Windows installer packaging, macOS packaging on both
architectures, and source-free payload validation before publication.

## Checksums

Download `SHA256SUMS.txt` with the installer and verify the selected installer's
SHA-256 digest before running it.

## Known Limitations

The Windows and macOS artifacts are unsigned and not notarized. Windows
SmartScreen or macOS Gatekeeper may display a warning before installation.
